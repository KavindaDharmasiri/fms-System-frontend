Badge

In UI/UX design, a badge is a small visual element or icon used to convey specific information or status within a user interface. Common uses include notification badges for alerts, status badges for task completion, achievement badges for milestones, and labels for categorization. Badges serve as efficient visual cues, enhancing the overall user experience by providing quick and clear information to users.
